账号绑定 & OAuth 授权

通过 OAuth 2.0 Authorization Code Flow with PKCE 安全绑定企业 X 账号，座席无需保存密码

📋 功能概述

企业用户授权其 X 账号到平台，获取 Access Token + Refresh Token，支持后台静默续期。

  • OAuth 2.0 PKCE（3-legged 用户上下文）
  • Access Token 2 小时过期，Refresh Token 长期
  • offline.access 换取 Refresh Token 自动续期
  • 支持多租户多账号绑定

🔗 Demo 后端路由 → X 官方 API

以下 /api/x/* 路由由 Demo 后端定义，内部调用 X 官方 OAuth 2.0 API。

GET/api/x/auth 构建授权 URL 并重定向用户到 X 登录
↓ 内部调用 X 官方：GET https://x.com/i/oauth2/authorize 📖
GET/api/x/callback 接收 X 回调，用 authorization code 换取 token
↓ 内部调用 X 官方：POST https://api.x.com/2/oauth2/token（grant_type=authorization_code） 📖
GET/api/x/status 查询本地绑定状态（纯本地，不调用 X API）
POST/api/x/refresh 用 refresh_token 获取新的 access_token
↓ 内部调用 X 官方：POST https://api.x.com/2/oauth2/token（grant_type=refresh_token） 📖
POST/api/x/unbind 撤销 token 并清除本地绑定
↓ 内部调用 X 官方：POST https://api.x.com/2/oauth2/revoke 📖
POST/api/x/unbind-all 一键解绑所有账号（演示用，便于多次绑定流程）

📚 官方文档

  • OAuth 2.0 Authorization Code + PKCE
  • User Access Token
  • Developer Apps 管理

⚙️ X 开发者后台配置

  1. 在 console.x.com 创建 Project + App
  2. App settings → User authentication settings 启用 OAuth 2.0
  3. Type of App 选 Web App（confidential client）
  4. App permissions 选 Read and write and Direct messages
  5. Callback URL：http://localhost:3000/api/x/callback
  6. 获取 Client ID / Client Secret 填入 .env

私信收发

通过 X Activity API Webhook 实时接收私信，用 chat-xdk 在服务端解密新版 Chat 端到端加密私信

📋 功能概述

入站走 XAA Webhook 实时推送，新版 Chat 加密私信用 chat-xdk 服务端解密展示明文。

  • 实时接收私信（XAA Webhook）
  • 旧版 DM 事件：dm.received / dm.sent（明文）
  • 新版 Chat 事件：chat.received / chat.sent（E2EE 加密）
  • Juicebox PIN 解锁真机身份，服务端解密加密私信
  • 解密明文自动展示，无需手动操作

🔐 X Chat 端到端加密 + chat-xdk 服务端解密

X 新版 Chat 采用端到端加密（E2EE）。chat.received 的 Webhook 推送含元数据与密文 encoded_event（及可选 conversation_key_change_event），可用 X 官方 @xdevplatform/chat-xdk 在服务端解密为明文。

本 Demo 走 Juicebox PIN（真机身份） 路径：用账号的 4 位 XChat PIN 从 Juicebox 恢复真机身份密钥（createChat → unlock），即可解密该账号在网页/App 真实收发的加密私信。解密要点：登记会话双方全部签名公钥版本 + 先吸收 key change 提取会话密钥。

⚠️ PIN 是账号 E2E 最高凭据，从服务端 .env 的 XCHAT_PIN 读取、仅在内存使用、不落盘。服务端持有 PIN 会削弱端到端保证，此为 Demo 演示取舍。

🔗 后端接口

POST/api/x/webhook/register注册 Webhook URL
PUT/api/x/webhook/:id/validate重新验证失效 Webhook
POST/api/x/webhook/subscribe订阅 dm/chat 事件
POST/api/x/dm/send发送私信（旧版 DM）
GET/api/x/dm/local-events本地缓存事件（含解密后的 Chat 明文）
POST/api/x/chat/unlockJuicebox PIN 解锁真机身份
GET/api/x/chat/identity-status查询解锁状态
GET/api/x/chat/local-events已解密的 Chat 事件

加密私信解密核心：webhook 收到 chat.received → 用已解锁真机身份 decryptEvents([keyChange, msg]) 提取会话密钥并解密 → 明文写入本地缓存供前端轮询展示。

⚙️ 配置步骤

  1. 完成页面 1 账号绑定
  2. 准备公网 HTTPS 回调（本地用 ngrok，无端口号）
  3. 点击「注册 Webhook」→ X 发起 CRC 校验
  4. 点击「订阅 Chat 事件」（收加密私信）
  5. 服务端 .env 配置 XCHAT_PIN（账号 XChat PIN），进页面自动解锁真机身份
  6. 对方发来的加密私信经 Webhook 实时解密，自动展示明文

评论回复

通过 X Activity API Webhook 实时监听 @提及/评论，通过发帖接口回复评论

📋 功能概述

入站监听 post.mention.create 实时推送，出站发推文并指定 in_reply_to_tweet_id 完成回复。

  • 实时监听 @提及（XAA / post.mention.create）
  • 回复评论（POST /2/tweets + reply.in_reply_to_tweet_id）
  • 轮询兜底（GET /2/users/:id/mentions）
  • 支持图片/视频附件

🔗 后端接口

POST/api/x/webhook/register注册 Webhook（同私信）
POST/api/x/activity/subscribe订阅 post.mention.create
POST/api/x/tweets/reply发送评论回复
GET/api/x/mentions查询近期提及（轮询兜底）
GET/api/x/mentions/local-events本地缓存（Webhook 推送）

📚 官方文档

  • Reply to a Post
  • User Mentions Timeline
  • XAA 事件类型
  • Filtered Stream（替代方案）

⚙️ 配置步骤

  1. 完成账号绑定且 Webhook 已注册
  2. 点击「订阅提及事件」→ post.mention.create
  3. 他人 @提及时事件实时推送
  4. 点击某条提及右侧「回复」按钮
  5. 输入回复内容并发送
  6. 系统调用 POST /2/tweets 携带 in_reply_to_tweet_id

⏱️ 速率限制

POST /2/tweets 每用户 100 次/15 分钟（硬限），App 级 10,000 次/24 小时。

带 URL 的帖计费高达 $0.200/次，需评估短链/去链策略。
